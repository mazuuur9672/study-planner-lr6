# Планувальник навчання

Навчальний Streamlit-застосунок для студента. Дозволяє вести предмети та завдання, планувати терміни, відмічати виконання й переглядати прогрес.

Автор — Мазур Олександр. Лабораторна робота №6 з дисципліни «Інформаційні технології», варіант 13.

## Можливості

- Три сторінки з боковою навігацією — «Завдання», «Предмети», «Про автора».
- Додавання, перегляд, редагування та видалення завдань і предметів.
- Пошук у назвах, фільтри за предметом і виконанням.
- Показники загальної кількості, виконаних і прострочених завдань.
- Діаграма кількості завдань за предметами.
- Перевірка порожніх значень, дублікатів і зв’язків між записами.

## База даних

Використано SQLite та дві пов’язані таблиці.

- subjects — id, name.
- tasks — id, subject_id, title, due_date, priority, done.

Поле tasks.subject_id посилається на subjects.id. Видалення предмета із завданнями заборонено. SQL-значення передаються параметрами, зміни виконуються в транзакціях. Схема міститься у schema.sql, функції роботи з БД — у db.py.

На першому запуску база автоматично отримує 3 предмети та 8 демонстраційних завдань. Повторне виконання скрипта зберігає поточні записи й не дублює початкові дані.

**Обмеження хмарної версії.** Файл SQLite розміщується в локальній файловій системі Streamlit Community Cloud. Зміни можуть зникнути після перезапуску або повторного розгортання. Демонстраційні дані спільні для відвідувачів. Дані першого запуску відновлюються з коду, якщо файл БД створюється заново.

## Локальний запуск

Перевірено на Python 3.11.3. У Windows PowerShell відкрийте папку проєкту та виконайте наведені команди.

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
~~~

У Linux або macOS після створення середовища використовуйте .venv/bin/python.

## Структура

- app.py — інтерфейс і три сторінки.
- db.py — створення БД, демонстраційні дані та CRUD.
- schema.sql — відтворювана структура таблиць.
- requirements.txt — залежності.
- .streamlit/config.toml — тема інтерфейсу.
- .gitignore — виключення середовища, кешів, БД і секретів.
